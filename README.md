# South African Insurance Claims Analytics System

## Project Overview

This project analyzes insurance claims data using Python, SQL, cloud databases, and interactive visualizations. The goal is to generate business insights from insurance claims data while demonstrating cloud-based analytics workflows.

## Project Architecture

CSV Dataset
      ↓
Data Cleaning (Python/Pandas)
      ↓
Supabase Cloud Database
      ↓
SQL Analysis
      ↓
Streamlit Dashboard
      ↓
Business Insights

## Technologies Used

- Python
- Pandas
- SQL
- Supabase
- Streamlit
- Plotly
- Git & GitHub

## Features

- Claims summary metrics
- Claims by province analysis
- Claims by type analysis
- Claim status monitoring
- Monthly claims trends
- Interactive dashboard filters
